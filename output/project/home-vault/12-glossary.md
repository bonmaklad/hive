# Glossary

> Status: Draft for client approval  
> Version: 0.1  
> Prepared: 15 July 2026  
> Product name: Home Vault (working title)

| Term | Meaning |
| --- | --- |
| Asset | An appliance, fixture, system or other item recorded at property or room level. |
| Core information vault | The free one-property record for rooms, photos, paint/finish details and documents. |
| Expense | An ongoing operating cost such as electricity, gas, rates, cleaning or maintenance. |
| Property Information Report | The proposed customer-facing name for the consolidated owner report; final naming requires approval. |
| Property Passport | A future buyer-safe, potentially separately charged report and ownership-transfer record. |
| Renovation cost | Labour, material or related improvement cost kept distinct from assets and ongoing expenses. |
| Room | A named area used to organise photos, finishes, assets, tasks, costs and comments. |
| System-generated task | A task proposed or created from an approved reminder, asset date or future guidance rule. |
