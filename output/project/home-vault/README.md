## Document lifecycle

1. Client reviews the DOCX and approval questions.
2. Approved changes are reflected in the JSON source of truth.
3. Stable feature, requirement and BDD IDs are retained.
4. Detailed design and delivery tickets reference those IDs.
5. Changes after approval are recorded as explicit scope decisions.
